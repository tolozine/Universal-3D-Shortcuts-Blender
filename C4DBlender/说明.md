# C4DBlender 使用说明

这套配置的目标：让已经习惯 Blender 默认键位的用户，在 Cinema 4D 中使用相近的快捷键。

## 文件内容

- `Universal_Blender.res`：C4D 快捷键配置文件。
- `scripts/`：原项目自带的 C4D Python 脚本，保持不变。

## 安装

1. 将本目录下 `scripts` 文件夹里的 11 个 `.py` 文件复制到 C4D 的脚本目录，例如：

   `%AppData%\Maxon\<你的C4D版本>\library\scripts`

   复制后目录结构应为：

   `...\library\scripts\Visibility Toggle.py`

2. 打开 Cinema 4D：

   `Window -> Customization -> Command Manager -> File -> Load`

3. 选择本目录下的 `Universal_Blender.res` 并加载。

## 需要注意

- C4D 没有 Blender 那种严格的 Object/Edit Mode 切换，因此 `Tab` 暂未映射。
- `1/2/3` 的边模式命令 ID 是从原项目资源文件中推断的，加载后请用 Command Manager 确认实际名称。
- 本目录中的 `.res` 只覆盖常用操作，不是完整键位映射。你可以在此基础上继续按需扩展。
